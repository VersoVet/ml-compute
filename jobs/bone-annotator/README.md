# bone-annotator YOLOv8 Training Job Template

Job template for training YOLOv8 object detection models on bone annotation datasets.

## Features

- YOLOv8 model variants (nano, small, medium, large, extra-large)
- Configurable epochs, batch size, learning rate
- Automatic model checkpoint saving
- Metrics logging (mAP50, mAP50-95, losses)

## Submitting the Job

### Basic YOLOv8m Training

```bash
curl -X POST http://10.0.0.44:9469/api/jobs \
  -H "Content-Type: application/json" \
  -d '{
    "name": "bone-annotator-yolo-$(date +%s)",
    "entrypoint": "python jobs/bone-annotator/train_yolo.py",
    "runtime_env": {
      "working_dir": "/opt/onyx/skills/ml-compute",
      "env_vars": {
        "DATASET_YAML": "/opt/onyx/skills/bone-ml/datasets/current/dataset.yaml",
        "MODEL_BASE": "yolov8m.pt",
        "EPOCHS": "100",
        "BATCH_SIZE": "16",
        "LEARNING_RATE": "0.001",
        "ML_MODELS_DIR": "/opt/onyx/skills/bone-ml/models"
      }
    },
    "submit_kwargs": {
      "num_cpus": 8,
      "num_gpus": 1,
      "memory": 16000000000
    }
  }'
```

## Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `DATASET_YAML` | Yes | — | Path to YOLO dataset.yaml (from bone-ml dataset service) |
| `MODEL_BASE` | No | `yolov8m.pt` | Base model: yolov8n/s/m/l/x (nano/small/medium/large/xlarge) |
| `EPOCHS` | No | 100 | Number of training epochs |
| `IMGSZ` | No | 640 | Image size (pixels) |
| `BATCH_SIZE` | No | 16 | Batch size |
| `LEARNING_RATE` | No | 0.001 | Initial learning rate |
| `DEVICE` | No | `0` | CUDA device ID (0, 1, 2, ...) or `cpu` |
| `ML_MODELS_DIR` | No | `/opt/onyx/skills/bone-ml/models` | Directory to save trained model |

## Model Selection Guide

| Model | Speed | Accuracy | Memory | Best For |
|-------|-------|----------|--------|----------|
| **yolov8n** | Very Fast | Good | 2GB | Real-time on edge devices |
| **yolov8s** | Fast | Better | 4GB | Fast inference + good accuracy |
| **yolov8m** | Medium | Good | 8GB | **Recommended** — good balance |
| **yolov8l** | Slow | Better | 16GB | Maximum accuracy |
| **yolov8x** | Very Slow | Best | 24GB | Highest accuracy (resource-intensive) |

## Monitoring the Job

```bash
# List all jobs
curl http://10.0.0.44:9469/api/jobs

# Get job status and logs
curl http://10.0.0.44:9469/api/jobs/{job_id}

# Stream logs (tail -f style)
curl http://10.0.0.44:9469/api/jobs/{job_id}/logs?follow=true
```

## Output

Training produces files in `ML_MODELS_DIR`:
- `bone-annotator-yolov8m-{timestamp}.pt` — Trained model weights
- `bone-annotator-yolov8m-{timestamp}-metrics.json` — Training metrics (mAP50, mAP50-95, losses)

## Dataset Format

The job expects a standard YOLO `dataset.yaml`:

```yaml
path: /abs/path/to/dataset
train: train/images
val: val/images
test: test/images
nc: 6
names: {0: bone_class_0, 1: bone_class_1, ...}
```

Generated by the bone-ml dataset service.

## Workers

Job executes on:
- **OnyxPoint** (10.0.0.86): GPU worker with NVIDIA T1000, 10 CPUs, 23GB RAM
- **Glia** (10.0.0.8): CPU worker with 20 CPUs, 47GB RAM

## Example: Full Training Pipeline

1. **Prepare dataset** (via bone-ml dataset service)
   ```bash
   curl -X POST http://10.0.0.44:8079/api/dataset/build \
     -d '{"name": "bone-dataset-v2"}'
   ```

2. **Submit training job**
   ```bash
   curl -X POST http://10.0.0.44:9469/api/jobs -d '...' # See examples above
   ```

3. **Monitor job progress**
   ```bash
   curl http://10.0.0.44:9469/api/jobs/{job_id}
   ```

4. **Use trained model for inference** (via bone-annotator predict service)
   ```bash
   curl -X POST http://10.0.0.44:8079/api/predict \
     -F "image=@photo.jpg"
   ```

The newest trained model (by mtime) is automatically used for predictions.
